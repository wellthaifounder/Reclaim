# Reclaim — Ready-to-Paste AI Logo Prompts

> Copy these straight into the tools. Order of use: **Recraft** (vector, primary) →
> **Midjourney** (mood, raster) → **Ideogram** (anything with the word "Reclaim").
> Then refine the winner in Figma/Illustrator. Brand colors: teal `#0e9b94`, gold `#e0b03f`,
> navy `#1a2238`.

## Recraft V3 — primary (true vector output) — https://recraft.ai

Set **Style → Vector / Logo**, **no background**, then paste one prompt per run. Generate 20–40,
keep the 3–4 strongest per direction.

## Refinement note

AI gives you the _direction_, rarely the shippable file. Bring the winner into **Figma** (or Illustrator):

- redraw on a clean geometric grid, single consistent stroke weight,
- build the horizontal `Reclaim.health` lockup with a real typeface,
- test at 16×16 and in pure single-color (black) for the PDF stamp,
- export `favicon.svg` + PNG set.

Asset swap into `public/` happens in **Phase 6** (the rebrand phase) — not before.
